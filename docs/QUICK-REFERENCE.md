# คู่มือการใช้งาน zigvim (Quick Reference)

## การติดตั้งและรัน

```bash
cd ~/zigvim
zig build
./zig-out/bin/zigvim [ชื่อไฟล์]
```

## ตัวอย่างการใช้งาน

### เปิดไฟล์ที่มีอยู่
```bash
./zig-out/bin/zigvim myfile.txt
```

### สร้างไฟล์ใหม่
```bash
./zig-out/bin/zigvim newfile.txt
```

### เปิดโดยไม่ต้องระบุไฟล์
```bash
./zig-out/bin/zigvim
```

## โหมดการทำงาน (Modes)

zigvim มี 3 โหมดหลัก เหมือน Vim:

### 1. Normal Mode (โหมดเริ่มต้น)
- ใช้สำหรับเลื่อน cursor และรันคำสั่ง
- แสดง `NORMAL` ที่ status bar

**คำสั่งที่ใช้ได้:**
- `i` หรือ `a` - เข้า Insert mode
- `:` - เข้า Command mode
- `h`, `j`, `k`, `l` - เลื่อน cursor (ซ้าย, ลง, ขึ้น, ขวา)
- `x` - ลบตัวอักษรที่ cursor
- `d` - ลบทั้งบรรทัด
- Arrow keys - เลื่อน cursor
- Ctrl+Q - ออกทันที
- Ctrl+S - บันทึกไฟล์

### 2. Insert Mode
- ใช้สำหรับพิมพ์ข้อความ
- แสดง `INSERT` ที่ status bar

**วิธีเข้า:**
- กด `i` ใน Normal mode

**วิธีออก:**
- กด `Esc` เพื่อกลับ Normal mode

**การใช้งาน:**
- พิมพ์ตัวอักษรได้ปกติ
- Enter - ขึ้นบรรทัดใหม่
- Backspace - ลบตัวอักษร
- Arrow keys - เลื่อน cursor
- Ctrl+S - บันทึก
- Ctrl+Q - ออกทันที

### 3. Command Mode
- ใช้สำหรับรันคำสั่ง
- แสดงคำสั่งที่กำลังพิมพ์ที่ message bar (บรรทัดล่างสุด)

**วิธีเข้า:**
- กด `:` ใน Normal mode

**วิธีออก:**
- กด `Enter` เพื่อรันคำสั่ง
- กด `Esc` เพื่อยกเลิก

## คำสั่งที่ใช้บ่อย (Common Commands)

| คำสั่ง | คำอธิบาย |
|--------|----------|
| `:w` | บันทึกไฟล์ |
| `:q` | ออกจากโปรแกรม (จะเตือนถ้ายังไม่ได้บันทึก) |
| `:wq` หรือ `:x` | บันทึกแล้วออก |
| `:q!` | ออกโดยไม่บันทึก (ทิ้งการเปลี่ยนแปลงทั้งหมด) |

## ตัวอย่าง Workflow

### แก้ไขไฟล์ที่มีอยู่
```
1. เปิดไฟล์: ./zig-out/bin/zigvim myfile.txt
2. กด i เพื่อเข้า Insert mode
3. พิมพ์หรือแก้ไขข้อความ
4. กด Esc เพื่อกลับ Normal mode
5. กด : แล้วพิมพ์ wq แล้วกด Enter
```

### สร้างไฟล์ใหม่
```
1. เปิดไฟล์ใหม่: ./zig-out/bin/zigvim newfile.txt
2. กด i เพื่อเข้า Insert mode
3. พิมพ์ข้อความ
4. กด Esc เพื่อกลับ Normal mode
5. กด : แล้วพิมพ์ wq แล้วกด Enter
```

### ออกจากไฟล์โดยไม่บันทึก
```
1. กด Esc เพื่อให้แน่ใจว่าอยู่ใน Normal mode
2. กด : แล้วพิมพ์ q! แล้วกด Enter
```

## Status Bar

Status bar แสดงข้อมูลสำคัญ:
```
 INSERT myfile.txt [+] - 10 lines         5:10
```

- `INSERT` - โหมดปัจจุบัน (NORMAL, INSERT, หรือ COMMAND)
- `myfile.txt` - ชื่อไฟล์
- `[+]` - ไฟล์ถูกแก้ไขแต่ยังไม่ได้บันทึก
- `10 lines` - จำนวนบรรทัดทั้งหมด
- `5:10` - ตำแหน่ง cursor (บรรทัดที่ 5, คอลัมน์ที่ 10)

## Message Bar

Message bar แสดงข้อความจากโปรแกรม:
- ข้อความต้อนรับเมื่อเปิดไฟล์ว่าง
- สถานะการบันทึก ("Saved to myfile.txt (123 bytes)")
- ข้อความเตือน ("E37: No write since last change")
- คำสั่งที่กำลังพิมพ์ใน Command mode (เช่น `:wq`)

## เคล็ดลับ (Tips)

1. **ถ้าไม่แน่ใจว่าอยู่ในโหมดไหน** ให้กด `Esc` สองครั้ง จะกลับสู่ Normal mode เสมอ

2. **บันทึกบ่อยๆ** ใช้ `Ctrl+S` เพื่อบันทึกได้ทุกเมื่อ

3. **ออกอย่างรวดเร็ว** ใช้ `Ctrl+Q` เพื่อออกได้ทันที (แต่การเปลี่ยนแปลงจะหายไป)

4. **ตรวจสอบก่อนออก** ดูที่ status bar ว่ามี `[+]` หรือไม่ ถ้ามี แปลว่ายังไม่ได้บันทึก

5. **ยกเลิกการเปลี่ยนแปลง** ใช้ `:q!` เพื่อออกโดยไม่บันทึก

## ปัญหาที่พบบ่อย (Troubleshooting)

### พิมพ์ตัวอักษรไม่ได้
- ตรวจสอบว่าอยู่ใน Insert mode หรือไม่ (กด `i`)
- ดูที่ status bar ว่าแสดง `INSERT` หรือไม่

### คำสั่ง : ไม่ทำงาน
- ตรวจสอบว่าอยู่ใน Normal mode ก่อนกด `:`
- ดูที่ message bar (บรรทัดล่างสุด) ว่าแสดง `:` หรือไม่

### ไฟล์ไม่ถูกบันทึก
- ตรวจสอบว่าระบุชื่อไฟล์หรือไม่
- ใช้ `:w` เพื่อบันทึก
- ถ้าไม่มีชื่อไฟล์ ให้ใช้ `:wq` แล้วระบุชื่อไฟล์

### ออกจากโปรแกรมไม่ได้
- ใช้ `:q!` เพื่อบังคับออก
- หรือใช้ `Ctrl+Q`
